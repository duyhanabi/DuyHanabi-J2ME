# DuyHanabi J2ME

[Tiếng Việt](README.md)

Bring classic Java games back to your Android phone. Add a game, adjust the screen, and set up the controls the way you like.

## Make it yours

- **Add games easily:** open `.JAR` or `.JAD` files. `.ZIP`, `.RAR`, and `.7Z` files are supported too. Game packages prepared for DuyHanabi can be recognized for a quicker import.
- **Customize your play:** change screen size and orientation, adjust image display, set a frame-rate limit, and arrange the virtual keyboard.
- **Handy tools:** check game speed, view logs, take screenshots, automate taps, and record or replay actions.
- **Play your way:** save settings for each game. The app can pause when idle and supports a floating window on compatible devices.
- **Choose where data goes:** keep game data in the app's private storage or select another folder after granting access.
- **Vietnamese interface:** the app starts in Vietnamese.

## Download and install

[Download DuyHanabi J2ME for Android](https://github.com/duyhanabi/DuyHanabi-J2ME/releases/latest)

Open the downloaded APK to install it. Android may ask you to allow installs from this source. The app shows progress while adding a game; large or merged games may take longer.

## Good to know

- Compatibility varies by game; some may behave differently or require a newer Android version.
- Floating windows and choosing a storage folder depend on device support and the permissions you grant.
- The app is based on J2ME Loader and includes third-party libraries. License and attribution details are included with the release.
